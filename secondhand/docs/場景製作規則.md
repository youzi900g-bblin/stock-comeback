# 場景製作規則

場景只畫背景，人物（玩家與 NPC）另外疊上去。這份規則整理自網路上的像素場景教學與我們一路修改的結果。
程式在 `tools/pixel_art/scenes.py`（小套房在 `room.py`），輸出到 `art/`。目前有：小套房（白天、夜晚、整理後）、包貨角落、咖啡廳、街頭。

## 參考來源（網路查到的重點）

- 深度靠前景、中景、後景分層；後景細節要克制，否則畫面變平、搶走主角；幾層就夠，不必很多：[Slynyrd Pixelblog 62（風景背景）](https://www.slynyrd.com/blog/2026/5/27/pixelblog-62-landscape-backgrounds)、[Breaking Down Backgrounds：深度基礎](https://www.patreon.com/vampbyte/posts/breaking-down-2-32930587)。
- 前景飽和且深，後景降低飽和度往後退；用暖色對比冷色環境來引導視線；限制色票讓畫面統一：[Icons8：像素環境教學](https://blog.icons8.com/articles/how-to-create-a-beautiful-pixel-art-environment-in-clip-studio-paint/?amp=1)、[Slynyrd Pixelblog 28（側視圖圖塊）](https://slynyrd.com/blog/2020/5/21/pixelblog-28-side-view-tiles)。
- 一個畫面一個焦點區；最亮的像素集中在焦點；次要光源不能和主光一樣亮；家具遵守同一個消失點；道具比例一致；一個主色加一個重點色：[像素桌面佈置的重點整理](https://www.ulanzi.com/blogs/knowledges/pixel-art-desk-setup-ideas)（偏一般室內設計，僅供參考）。
- 夜晚場景：底色是灰褐，顏色主要來自光源；主光在街面（路燈、店面、霓虹），由下往上暖色漸轉冷色；先畫霓虹再上色窗戶；前景暗、後方街道亮：[Slynyrd Pixelblog 42（賽博龐克像素）](https://slynyrd.com/blog/2023/1/30/pixelblog-42-cyberpunk-pixel-art)。
- 沒查到專講「遊戲室內場景」的像素教學，所以室內的比例與留白規則是我們自己訂的。

## 一、尺寸與站位

1. 一律 104×96 格，放大 8 倍輸出為 832×768。
2. 人物腳底落在第 93 列、高 53 格、站在約 CX±13 的範圍。場景的第 40 到 93 列、這個範圍內要保持安靜：低對比、少細節，不放高對比的圖樣（例如大棋盤格），人物才讀得出來。
3. 地面上緣在第 48 列。正面視角，所有家具正對畫面，不混用斜視角。

## 二、比例基準（以人物 53 格高為準）

| 物件 | 高度（距地面） |
|---|---|
| 門 | 至少 55 格 |
| 桌面、櫃台 | 約 22 到 26 格 |
| 椅座 | 約 12 到 14 格 |
| 窗台 | 約 25 到 28 格 |
| 床 | 約 14 到 16 格 |

同一張場景裡的同類物件比例要一致（兩張椅子一樣大）。

## 三、配色

1. 每個場景一組自己的配色：一個主色、一個重點色，加上中性色。
2. 後景（牆、天空、遠景）降低飽和度；中景（家具、店面）正常；前景（地上物件、桌椅）最飽和、最深。
3. 高飽和色只留給焦點，不要到處用。
4. 目前各場景的配色：
   - 小套房：淡紫牆、深木色、梅紅與粉。
   - 包貨角落：奶油牆、牛皮紙棕、薄荷綠、深石板灰；重點色珊瑚紅。
   - 咖啡廳：奶油牆、磚紅下半牆、濃縮咖啡深棕；重點色芥末黃與橄欖綠。
   - 街頭：黃昏的紫藍天空與冷灰水泥；重點色霓虹粉與青綠，暖黃路燈光。
   - 夜晚版：整張乘上藍紫調暗，再加光源。

## 四、焦點與留白

1. 每張只有一個焦點區：小套房是爆滿的衣櫃，包貨角落是書桌，咖啡廳是櫃台，街頭是店面與路燈。
2. 焦點周圍留白，不放小東西；最亮的像素與最高的對比集中在焦點。
3. 加一個道具前先問：它支持焦點還是和焦點搶？搶的就不加。
4. 兩種繁複的圖樣不要相鄰（例如棋盤地板貼著磚牆）；其中一個要簡化或降低對比。

## 五、光

1. 有光源才畫光暈，沒有光源就不畫。
2. 次要光源比主光暗；夜晚由下往上暖色漸轉冷色。
3. 夜晚版做法：整張調暗並偏藍，再重畫窗外與發光的物件，光源（串燈、路燈、招牌）周圍加一圈柔光。

## 六、圖層順序

1. 由後往前：牆與地板、牆面物（窗、黑板、海報）、靠牆家具、地面平貼物（地毯）、地上物件（箱子、盆栽）、前景桌椅、光效。
2. 同一層內，依物件底邊的列數由小到大畫（越靠後越先畫）。
3. 程式用 `Scene.add(層, 底邊列, 畫法)` 登記，最後依層與底邊排序再畫，不要手寫先後。

## 七、對稱與圖樣

1. 條紋、櫃門、抽屜、窗簾、遮陽篷、窗框十字：以物件中心為軸，由中心往兩側算位置，左右的數量與寬度相同。
2. 條紋數量用奇數時，兩端同色；磚縫每兩列錯開半塊；棋盤磚用固定格寬（8×8），不要混用不同尺寸。
3. 有自然不規則的東西（軟木板上的紙、散落的衣服）不必對稱，但要看起來刻意。

## 八、邊線與色階

1. 牆、地板、天空不描邊；家具、物件用依底色加深的邊線（乘 0.7）。
2. 色階：底色、亮、暗三階，不用漸層；大面積的漸變用色帶，色帶交界可用抖色（棋盤式交錯）過渡。
3. 材質靠圖樣：木板、磚、磁磚用重複圖樣，地毯用同心橢圓。

## 九、驗證清單

1. 放大 6 倍以上看一遍，再看實際顯示大小。
2. 疊上玩家與三位 NPC，確認站位區的人物讀得出來。
3. 轉成灰階看一遍：焦點區應該是對比最強的地方。
4. 檢查順序（有沒有該被擋住的東西畫在前面）與對稱（以中心對折比對）。
5. 既有的小套房圖、NPC 圖重畫後要與原圖一致（若是刻意修改，要寫明改了什麼）。
6. 手機寬度（375px）看過沒有被切到。

## 十、新增場景的流程

1. 先提案：用途、焦點、配色（主色、重點色）、光源、要放的物件清單。
2. 使用者確認後才畫。
3. 畫完先給使用者看，確認後才更新網址。
4. 場景不排程量產，需要時逐張處理。
