# 第一階段計畫

目標：做出一個可以單獨玩的最小版本。玩家創角、整理衣櫃、跟著教學賣出一件基本款，賺到第一筆錢，之後逐步認識市場價。

## 範圍

來自 `系統設計.md` 第七節。

包含：
1. 創角：名字、髮型、膚色、眼睛、眼珠顏色、嘴巴、雀斑、頭飾、眼鏡、上衣、下身，並可一鍵隨機外觀與隨機名字（體型固定中等，不開放）。
2. 衣櫃：顯示物品、分類檢視、每件選「賣」或「留」、容量上限。
3. 新手教學：
   - 第一步：只教賣一件衣物，包含標價、上架、等待、成交、拿到錢。
   - 第二步：第一次成交後，介紹基礎價值與市場價，之後逐步帶入標籤與流行。
4. 賣出基本款、拿到錢，作為後續收貨的本金。
5. 存檔：瀏覽器本機儲存，不需要登入。
6. 畫面：手機優先，色塊與文字卡片為主。

不包含（留到之後）：社群收貨、賣場評價、包貨出貨、議價、整理修補、換裝、NPC、收藏目標、開店。

## 預設的技術方向（待確認）

- 手機優先的網頁遊戲，存檔用 localStorage。
- 本 repo 的 `stock/` 專案是單一 `index.html` 加字型與自我檢查腳本。第一階段可沿用相同的做法，以純 HTML、CSS、JavaScript 為主。是否改用框架，由你決定。

## 資料結構草案

物品（Item）：

| 欄位 | 說明 |
| --- | --- |
| id | 唯一編號 |
| 名稱 | 顯示名稱 |
| 類型 | 衣服、包包、首飾、奢侈品、家具與裝飾 |
| 風格標籤 | 可多個；第一階段先放資料，不影響價格 |
| 狀況 | 分級待定 |
| 稀有度 | 待定 |
| 基礎價值 | 固定，玩家看得到 |
| 市場價 | 基礎價值乘上市場係數，第一階段市場係數固定 |
| 成本價 | 玩家取得時的價格 |
| 圖片 | 色塊或像素圖 |

玩家（Player）：名字、髮型、膚色、金錢、衣櫃容量、衣櫃物品、賣場上的物品、目前天數。

賣場物品（Listing）：物品 id、標價、上架天數、預計成交天數。

## 價格與成交的第一階段規則

- 市場價 = 基礎價值 × 市場係數（第一階段固定為 1，後續才加入流行與波動）。
- 標價與市場價的差距決定每天的成交機率：標價越低，當天賣掉的機率越高；標價越高機率越低（已改，原本是固定等待天數）。
- 等待天數到了就成交，不另加抽籤。
- 掛賣天數超過 5 到 10 天（確切天數待定）沒有成交，出現調價提示。
- 所有數值（等待天數與差距的關係、基礎價值、衣櫃容量、初始金錢）都是待定，實作時先用佔位值並標明。

## 驗收條件

- 新玩家從創角開始，不看說明就能完成「賣出第一件」。
- 關掉頁面再打開，進度還在。
- 手機直式畫面可以正常操作，沒有文字被截斷。
- 所有待定數值都標明是佔位值，集中放在同一個地方，方便之後調整。
