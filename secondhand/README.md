# 衣櫃塞不下（Overstuffed）

手機優先的網頁遊戲。玩家是一個愛買衣服、衣櫃已經爆滿的人：從清衣櫃賣基本款開始，在社群收貨、開網路賣場賺價差，把喜歡的留下來打扮自己，最後開自己的店。

遊戲名稱已定：英文《Overstuffed》，中文《衣櫃塞不下》。

## 現況

- 系統設計：完成大綱，數值全部待定。
- 美術方向：已定（3 頭身像素 Q 版，規格見 `docs/系統設計.md` 的「八-1、角色美術規格」）。
- 角色與房間：已有三位 NPC 角色與一個小套房背景的草圖，由程式產生。
- 程式：第一階段已實作（純 HTML、CSS、JavaScript，存檔用 localStorage）。用瀏覽器開啟 `index.html` 即可。所有未定數值集中在 `config.js`，標示【佔位值】。第一階段計畫見 `docs/第一階段計畫.md`。

## 重新產生圖片

需要 Python 3 與 Pillow（`pip install pillow`）。

```
python3 tools/pixel_art/build_art.py
```

圖片會輸出到 `art/`。也可以指定資料夾：`python3 tools/pixel_art/build_art.py 輸出資料夾`。

程式檔說明：

- `engine.py`：以圖層方式繪製人物，每個圖層自動加上依顏色加深的邊線；包含體型、膚色、臉部、髮型的繪製。
- `characters.py`：三位 NPC 的參數（伊瑪、艾蓮娜、由奈）。
- `room.py`：小套房背景與三人合照。
- `build_art.py`：一次輸出所有圖片。

## 還沒決定的事

見 `docs/系統設計.md` 第九節。已定案的有：美術風格、時間機制（每天結算）、遊戲名稱。

還沒決定的主要有：
- 物品與價格的實際數值（目前是佔位值，集中在 `config.js`）。
- 衣櫃初始容量與擴充的件數（目前初始 20 件為佔位值）。
- 滯銷提示的確切天數（5 到 10 天之間，目前暫用 7 天）。
- 流行換季的天數、多標籤合併的算法與加成幅度。
- 議價成功率、殺價幅度，以及整理修補的狀況分級與費用。
- 收藏目標的具體件數與獎勵。
- NPC 的具體任務內容、順序、關係好壞的判定與開店場景差異。
- 髮型與頭飾的完整清單。
- 風格標籤在這個尺寸下的辨識度驗證，特別是 vintage 與優雅、可愛之間。
