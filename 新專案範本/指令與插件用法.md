# Claude Code 指令總表

整理日期：2026-11-22

## 先看這裡：新專案要自己重裝的東西

- 斜線指令、內建指令（`/clear`、`/compact`、`/model`、`/code-review` 等）和 Design 插件、Playwright 屬於 Claude 帳號，新專案直接可用。
- Hallmark、Ponytail、Unslop 只裝在舊專案，新專案要用就得在新專案裡用 `/plugin` 重新安裝。
- GitHub 插件與 Axe 在舊專案連線失敗，新專案不用特別處理，需要時再設定（見文末）。

## Ponytail 模式

| 指令 | 效果 |
|---|---|
| `/ponytail lite` | 照要求做，並提醒更簡單的做法 |
| `/ponytail` | 預設模式，做最小但完整的修改 |
| `/ponytail ultra` | 動手前先質疑需求是否必要 |
| `/ponytail off` | 關閉，也可以說「normal mode」 |
| `/ponytail-gain` | 查看節省程式碼與成本的數據 |
| `/ponytail-help` | 顯示快速說明 |

短指令沒有出現時，改打完整名稱，例如 `/ponytail:ponytail-review`。

## 建議的做事順序

1. 做畫面：新畫面用 `/hallmark`，舊畫面用 `/unslop`。
2. 修體驗：`/design:design-critique`，再用 `/design:ux-copy` 修文字。
3. 查無障礙：`/design:accessibility-review`。
4. 實測：用 Playwright 跑一輪，包含手機版面。
5. 交付前：`/code-review`，對外上線再加 `/security-review`。

## 還需要設定的項目

- **Design 的外部服務：** Figma、Slack、Notion、Linear、Asana、Atlassian、Intercom 要先在 `/mcp` 授權。沒用這些服務就不必處理。
- **Axe：** 需要 Axe DevTools 訂閱，有訂閱再執行 `/axe-accessibility:mcp-setup`。自動修復會按問題數量扣點數。沒有訂閱就用 `/design:accessibility-review`。
- **GitHub 插件：** 需要設定 `GITHUB_PERSONAL_ACCESS_TOKEN` 環境變數。`gh` 已能使用，可以先不處理。
- **Playwright 暫存：** 測試時可能在專案產生 `.playwright-mcp/` 資料夾，不需要加入 git。
